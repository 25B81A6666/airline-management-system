 
 About the Project

This is a simple Airline Management System developed using C and Data Structures. The project represents airports and routes using a graph and provides basic operations for managing and exploring the airline network.

Technologies Used

* C
* Data Structures
* Graph
* Adjacency Matrix

Features

* Add a new airport
* Add a route between airports
* Display the airline network
* Check for a direct route
* BFS traversal
* DFS traversal
* Menu-driven program

 Concepts Used

* Arrays
* Strings
* Graphs
* Adjacency Matrix
* Breadth First Search (BFS)
* Depth First Search (DFS)

 How to Run

1. Download or clone this repository.
2. Open the C file in a C compiler.
3. Compile the program.
4. Run the executable.
5. Use the menu options to manage and explore the airline network.

 Project Purpose

This project was developed as part of academic work to practice Data Structures and understand graph traversal using a practical airline network example.
